# Lost Meshcore Repeater

The device is harmless. It is a Meshcore network repeater.

Meshcore allows hobbyists to set up their own private wireless networks.

Official homepage: [https://meshcore.io](https://meshcore.io)

Hashtag: `#meshcore` on all social media.

If the device cannot remain where it was found, please place it somewhere nearby. The solar panel needs as much sunlight as possible.

This page is in no way affiliated with the owner of the device on which this address was found.
